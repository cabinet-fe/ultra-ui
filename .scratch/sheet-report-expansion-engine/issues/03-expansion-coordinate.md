# 03 — 扩展坐标系（纯计算层）

**What to build:** `packages/sheet/src/report/render/` 的模板索引与扩展坐标计算：由绑定的 `rowParent` / `colParent` 构建行树与列树，枚举每个格的实例，计算子树跨度，产出逻辑格 → 物理区间的映射。本票**不产出任何快照**、不做取值填充，是一段可无头穷举单测的纯计算。

**Blocked by:** 02 — 绑定模型定稿与旧角色体系删除

**Status:** ready-for-agent

- [ ] `render/template-index.ts`：模板一次性索引——绑定 `Map<地址键, ReportBinding>`、静态格按地址直查、行树与列树（父 → 子列表）。替换现状的线性扫（`bindingCells` 每次重建数组、`templateCell` 用 `cells.find`、`expansionBlocks` 每行重算）
- [ ] 索引构建时校验结构约束（ADR-0005 决策 3）：每格最多一个 `rowParent` + 一个 `colParent`；父格必须指向存在的绑定格；父链不得成环。违反时抛可读错误（附单元格 A1 标签），不静默降级
- [ ] `render/coordinate.ts`：实例枚举与跨度计算
  - 扩展格实例数：`aggregate: 'group'` 取字段去重值数（按 `sort` 排序）、`'list'` 取记录数、`expand: 'none'` 恒为 1
  - 每个实例携带一个过滤条件（祖先父格实例的字段值合集）；父格约束**只在同数据集内生效**，跨数据集绑定按自己的 `dataset` 独立展开
  - 父格实例跨度 = 其子树展开量（行方向取行跨度、列方向取列跨度）
  - 逻辑格 → 物理区间映射对**全部单元格生效**，含静态格与合并区域（ADR-0005 决策 2）：模板是逻辑网格，输出是物理网格
- [ ] 空展开：实例数为 0 的扩展格产出 0 行 / 0 列跨度，其子树整体不占位；静态格与表头照常映射
- [ ] `render/__test__/coordinate.test.ts` 穷举小 case：单级纵向、多级纵向嵌套、单级横向、多级列头（`colParent` 链）、行列同时展开、`mergeSpan` 开关下的跨度、静态格被展开推移、空展开、跨数据集并存
- [ ] 断言只针对坐标与跨度（不涉及取值与样式），便于用大量小 case 钉死几何正确性

## Comments

- **为何按「坐标计算 / 输出组装」切分而非按「纵向 / 横向」切分**：按纵横切会导致本票先写出一个只支持一维的坐标系、下一票再回头改它。按计算 / 组装切则本票是一段纯函数、能穷举单测，04 只做填值与组装。
