# 优化 Theme 组件设计

> 状态: 已执行

## 目标

重新优化设计 Theme 组件，使其更适合在宽容器下展示，解决上方分类导致下方设置面板太小的问题。同时优化颜色选择功能，既可以输入或选择具体的颜色值，也可以选择 CSS 变量。

## 内容

1. 分析 `ui/components/theme/theme.vue` 及相关组件，理解现有内容区与设置面板的布局方式。
2. 重构 Theme 组件布局，调整上方的分类与下方的设置面板，使其在宽容器及常见容器中能更好地利用空间（考虑左右结构或大幅扩展显示区域）。
3. 扩展颜色选择器功能，集成具体颜色选取与 CSS 变量选取的切换支持。
4. 进行本地测试和类型校验，确保没有回归和功能异常。

## 影响范围

- `ui/components/theme/theme.vue`
- `ui/components/theme/style.scss`
- `ui/components/theme/schema.ts`
