# switch 组件动画丢失问题修复

> 状态: 已执行

## 目标

定位 `switch` 组件在切换时偶发性动画丢失的根因，特别是 `sample/App.vue` 中切换主题时出现的无过渡现象，并在不破坏现有 API 与视觉表现的前提下完成修复与验证。

## 内容

### 1. 复现与根因定位
- 检查 `sample/App.vue` 中主题切换场景与 `switch` 组件实现，确认动画丢失的稳定触发条件
- 分析 `switch` 的 DOM 结构、过渡样式与状态更新时机，定位为何在某些更新路径下浏览器不会触发预期 transition

### 2. 组件修复
- 调整 `switch` 组件实现或样式，确保在主题切换等场景下滑块位移和相关视觉反馈都能稳定触发动画
- 避免引入新的闪烁、布局抖动或状态同步问题

### 3. 验证
- 运行相关测试或类型检查，确认修复没有破坏现有行为
- 结合示例场景复查 `switch` 切换与主题切换时的动画表现

## 影响范围

- `sample/App.vue` — 调整 `.theme-transitioning` 的全局过渡策略，只覆盖持续时间与缓动曲线，避免主题切换时覆盖组件自身的 `transition-property`，修复 `switch` 在切换主题时滑块动画偶发丢失的问题
