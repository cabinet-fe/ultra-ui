# 间距规范 (Spacing)

间距是界面呼吸感和信息分组的重要工具。Ultra UI 采用基于 4px 的间距系统，确保整个界面的视觉节奏一致。

## 间距基数

Ultra UI 使用 **4px** 作为间距基数，所有间距值都是 4 的倍数。

**优势：**

- 视觉节奏一致
- 易于计算和记忆
- 适配各种屏幕密度

## 间距比例

| 等级 | 值   | 计算 | CSS 变量        | 用途       |
| ---- | ---- | ---- | --------------- | ---------- |
| 4xs  | 2px  | 0.5x | -               | 最小微调   |
| 3xs  | 4px  | 1x   | -               | 图标文字间 |
| 2xs  | 6px  | 1.5x | `--gap-small`   | 紧凑元素   |
| xs   | 8px  | 2x   | `--gap-default` | 元素内部   |
| sm   | 12px | 3x   | `--gap-large`   | 相关元素   |
| md   | 16px | 4x   | -               | 卡片内边距 |
| lg   | 24px | 6x   | -               | 区块间距   |
| xl   | 32px | 8x   | -               | 大区块     |
| 2xl  | 48px | 12x  | -               | 页面级     |
| 3xl  | 64px | 16x  | -               | 特殊场景   |

## 组件间距

### 内边距 (Padding)

组件内部的留白：

| 组件类型   | small      | default    | large      |
| ---------- | ---------- | ---------- | ---------- |
| 按钮       | 0.8em 水平 | 0.8em 水平 | 0.8em 水平 |
| 输入框     | 3px 水平   | 4px 水平   | 6px 水平   |
| 卡片       | 6px        | 8px        | 12px       |
| 弹窗主体   | 8px        | 8px        | 8px        |
| 下拉菜单项 | 8px 12px   | 8px 12px   | 12px 16px  |

### 外边距 (Margin)

组件之间的间距：

| 场景       | 推荐间距              |
| ---------- | --------------------- |
| 相邻按钮   | `--gap-default` (8px) |
| 表单项垂直 | 16px                  |
| 卡片间距   | 16px-24px             |
| 页面区块   | 24px-32px             |

## 响应式间距

在不同屏幕尺寸下调整间距：

| 断点            | 页面边距 | 区块间距 | 卡片间距 |
| --------------- | -------- | -------- | -------- |
| xs (< 600px)    | 12px     | 16px     | 12px     |
| sm (600-960px)  | 16px     | 20px     | 16px     |
| md (960-1280px) | 24px     | 24px     | 16px     |
| lg (> 1280px)   | 32px     | 32px     | 24px     |

## 组件内部间距规则

### 图标与文字

| 场景       | 间距  |
| ---------- | ----- |
| 按钮内图标 | 4-6px |
| 列表项图标 | 8px   |
| 标题前图标 | 8px   |

### 元素组合

| 组合类型      | 间距  |
| ------------- | ----- |
| 标签 + 输入框 | 4-8px |
| 输入框 + 提示 | 4px   |
| 按钮组相邻    | 8px   |
| 标签组相邻    | 4-6px |

## 负间距

在某些场景下使用负间距实现特殊效果：

| 场景           | 用法                           |
| -------------- | ------------------------------ |
| 叠加头像       | margin-left: -8px              |
| 紧贴边框       | margin: -1px                   |
| 抵消父元素边距 | margin: -16px 后 padding: 16px |

## 使用示例

### SCSS 中使用

```scss
.card {
  padding: fn.use-var(gap, default);

  &__header {
    padding: fn.use-var(gap, small) fn.use-var(gap, default);
    margin-bottom: fn.use-var(gap, default);
  }

  &__content {
    > * + * {
      margin-top: fn.use-var(gap, default);
    }
  }
}
```

### 动态间距

```vue
<template>
  <div :style="{ gap: `var(--gap-${size})` }">
    <slot />
  </div>
</template>
```

## 间距计算工具

### SCSS 函数

```scss
// 基于基数计算间距
@function space($multiplier) {
  @return #{$multiplier * 4}px;
}

// 使用
.element {
  padding: space(2); // 8px
  margin: space(4); // 16px
}
```

### CSS 自定义属性方案

```css
:root {
  --space-unit: 4px;
}

.element {
  padding: calc(var(--space-unit) * 2); /* 8px */
  margin: calc(var(--space-unit) * 4); /* 16px */
}
```

## 最佳实践

### ✅ 推荐

1. **使用变量**：优先使用 `--gap-*` 变量
2. **保持一致**：同类元素使用相同间距
3. **适度留白**：给予充足呼吸空间
4. **响应适配**：大屏可适当增加间距

### ❌ 避免

1. **奇数值**：避免 7px、13px 等非规律值
2. **过度密集**：避免间距过小导致拥挤
3. **随意值**：避免随意使用不同间距
4. **硬编码**：避免直接写死数值
