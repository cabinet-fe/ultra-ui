# UIcon — 图标容器

> `import type { IconProps } from '@veltra/desktop'`

> 类型：`../../../generated/types/icon.ts`

包裹 `@veltra/icons` 提供的 SVG 图标组件，控制其字体大小。渲染为 `<i class="u-icon">` 元素。

## Import

```ts
// UIcon 由 Vite 自动导入，无需手动 import
// 类型
import type { IconProps } from '@veltra/desktop'
```

> 示例见 [examples.md](./examples.md)
