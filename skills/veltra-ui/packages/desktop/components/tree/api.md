# UTree — 树形控件

> `import type { TreeProps, TreeEmit, TreeExposed } from '@veltra/desktop'`

> 类型：`../../../generated/types/tree.ts`

支持单选/多选、展开/折叠、过滤搜索、虚拟滚动（节点数 > 80 时自动启用）、右键菜单、自定义节点渲染。

## Import

```ts
// UTree 由 Vite 自动导入，无需手动 import
// 类型
import type { TreeProps, TreeEmit, TreeExposed } from '@veltra/desktop'
```
