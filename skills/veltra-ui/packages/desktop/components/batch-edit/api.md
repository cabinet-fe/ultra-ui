# UBatchEdit - 批量编辑

## 简介

用于左侧选择记录、右侧表单批量编辑字段的场景。

## 类型文件

见 `./types.d.ts`

## 示例

见 `./examples.md`

## 辅助工具

本组件通常配合以下工具来使用。

### FormModel

批量编辑右侧表单的数据与校验模型。

使用示例:

```ts
import { FormModel } from '@veltra/desktop'
```

### defineTableColumns

与 UTable 相同，为左侧表格列批量设置公共列属性。

使用示例:

```ts
import { defineTableColumns } from '@veltra/desktop'
```
