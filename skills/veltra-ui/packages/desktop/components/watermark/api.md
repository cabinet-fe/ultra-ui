# UWatermark — 水印

> `import type { WatermarkProps, WatermarkEmits, WatermarkExposed } from '@veltra/desktop'`

> 类型：`../../../generated/types/watermark.ts`

在页面或容器上叠加半透明水印文字或图片，通过 Canvas 生成平铺背景实现。支持旋转角度、字号、图片水印、传送至 body。
