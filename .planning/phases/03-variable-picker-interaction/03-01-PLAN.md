  <action>
Revalidate selection before insertion in handleVariableSelect (per RESEARCH Pattern 3 / Pitfall 3).

Inside editor.update(), before mutating:
1. Get targetNode via $getNodeByKey(nodeKey) — abort if null
2. Get selection via $getSelection() — abort if not $isRangeSelection
3. Get focusNode from selection.focus.getNode()

5. If !targetNode.getTextContent()?.includes('@'), abort (node content changed)
