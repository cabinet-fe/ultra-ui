# docs-mcp 文档标准

本标准约束推送到 docs-mcp 的 Markdown 文档。目标：文档既能被 FTS5 全文索引命中，又能让 AI 检索后直接读懂、用对。撰写或更新库文档时按此执行。

## Frontmatter 规范（硬性）

每个 `.md` 文件开头必须有 YAML frontmatter，`title` 必填非空：

```markdown
---
title: 快速开始
description: 五分钟上手指南
---

正文……
```

| 字段          | 必填           | 说明                                                                                     |
| ------------- | -------------- | ---------------------------------------------------------------------------------------- |
| `title`       | 是             | 短语级标题，可独立说明文档主题；检索结果按标题加权展示                                   |
| `description` | 否（强烈建议） | 一句话概述；出现在检索元数据中，帮助 AI 决定是否读全文                                   |
| `aliases`     | 否             | 场景别名/同义词列表（支持 YAML 列表或逗号分隔标量）；享与 title 同级的高检索权重（10.0） |
| `keywords`    | 否             | 核心关键词列表（支持 YAML 列表或逗号分隔标量）；享与 title 同级的高检索权重（10.0）      |
| 其他字段      | —              | 忽略（tags、author 等不入索引）                                                          |

### 兼容性要求

推送脚本与服务端是两套解析器，写法规范如下：

- 脚本（轻量校验）：识别顶层「键: 值」行，校验 `title` 是否存在非空；列表行与其余字段直接跳过
- 服务端（严格解析）：完整 YAML 解析（gopkg.in/yaml.v3），提取 `title`、`description`、`aliases`、`keywords`，格式错误即整批推送失败；重复字段取末个

因此 frontmatter 的撰写要求：

- 字段支持：`title`（必填）、`description`（可选）、`aliases`（可选列表或标量）、`keywords`（可选列表或标量）
- 列表支持 YAML 标准列表语法（`- 项`）、内联数组（`[a, b]`）或逗号分隔字符串（`"a, b"`）
- 禁止多行标量（`>-`、`|`）
- 禁止重复字段
- 禁止 BOM（脚本容忍 BOM，服务端会解析失败，文件统一 UTF-8 无 BOM）
- 值含特殊字符时用双引号包裹（两端都支持）

## 文件组织

- 文档放 `docs/` 目录（推送脚本默认扫描根，可用参数覆盖），递归扫描全部 `.md`；仓库根的 `README.md` 不在默认扫描范围，文档体系放 `docs/`
- 一主题一文件：主题越小，检索命中越精准；避免大杂烩长文档
- 路径即文档标识（`get_document` 按 `path` 取全文）：语义化、稳定、连字符命名，如 `docs/guide/installation.md`
- 路径是检索结果的回链地址，重命名等于让旧引用失效；确需重命名时整库重推并检查外部引用
- 目录内至少有一篇 `.md`，空目录会推送失败

## 内容标准

- 正文首段给出主题概述：AI 命中高亮片段后需要上下文判断相关性
- 代码块标注语言（`ts、`go 等）；示例完整可运行，只用公共 API
- 涉及配置项、环境变量、CLI 参数时用表格或列表逐项说明
- 中文撰写，专有名词、API 名称、代码标识符保留英文
- 禁止写入：内部实现细节、密钥/令牌、内网拓扑、未公开计划——文档对企业内所有使用者可检索

## 正反示例

好的（`docs/guide/installation.md`）：

````md
---
title: 安装
description: 通过包管理器安装 my-lib 并完成初始化
---

## 安装

```bash
npm install my-lib
```

## 初始化

……
````

坏的——缺 frontmatter，推送直接失败：

```md
# 安装

npm install my-lib
```

坏的——YAML 语法非法或 title 为空，推送直接失败：

```md
---
title: ''
description: 缺少有效标题
---
```
