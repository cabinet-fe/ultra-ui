# Vue 3.4

本文件只适用于 **3.4.x**。不要用 3.5 才有的 API（`useTemplateRef`、`useId`、`onWatcherCleanup`、props 解构响应式、`watch` 的 `pause`/`resume`、`deep: number`、懒水合、`Teleport defer`）。

## 模板引用

变量名必须与模板 `ref` 字符串一致。不要用 `useTemplateRef`。

```vue
<script setup>
import { ref, onMounted } from "vue";
const inputRef = ref(null);
onMounted(() => inputRef.value?.focus());
</script>
<template>
  <input ref="input" />
</template>
```

`v-for`：`const itemRefs = ref([])` + `ref="itemRefs"`。动态挂载用函数 `:ref="(el) => ..."`。

## Props

类型声明的默认值用 `withDefaults`。引用类型默认值必须是工厂函数。不要解构 props 当响应式（3.4 会断开）。

```ts
const props = withDefaults(defineProps<{ msg?: string; tags?: string[] }>(), {
  msg: "hello",
  tags: () => [],
});
```

传 composable / `watch`：`props`、`toRef(props, 'msg')`，或 `() => props.msg`。

## watch

- 只跑一次：`watch(source, cb, { once: true })`。
- 清副作用：回调第三个参数 `onCleanup`（没有 `onWatcherCleanup`）。
- `watch(reactiveObj, cb)` 默认 deep；getter 返回对象要 deep 时显式 `{ deep: true }`。能盯字段就盯字段。

## 其他

- 表单 `id` 不要 `Math.random()`（无 `useId`，自己保证稳定）。
- 已删除：Reactivity Transform、`v-is`、模板 `@vnode*`（改 `@vue:*`）。TSX 不要依赖全局 `JSX` 命名空间。
