# Vue 3.5

本文件适用于 **3.5.x**。按下面写，不要退回 3.4 的模板 `ref()` / `withDefaults` / 只用 `onCleanup` 参数。

## 模板引用

一律 `useTemplateRef`。参数是运行时 id，须与模板 `ref` 一致；变量名可以不同。类型由语言工具按模板推断。禁止 `const el = ref(null)` 接模板引用。

```vue
<script setup>
import { useTemplateRef, onMounted } from 'vue'
const input = useTemplateRef('input')
onMounted(() => input.value?.focus())
</script>
<template>
  <input ref="input" />
</template>
```

`v-for`：`const itemRefs = useTemplateRef('items')` + `ref="items"`（不要自己 `ref([])`）。自定义存放仍用函数 `:ref`。

## Props

解构默认就是响应式，默认值用 JS 语法。不要再上 `withDefaults`。

```ts
const { count = 0, msg = 'hello' } = defineProps<{
  count?: number
  msg?: string
}>()
```

解构结果不是 ref：`watch(() => count, ...)`，composable 传 `() => count`。`watch(count, ...)` 是错的。

## watch

- 只跑一次：`{ once: true }`。
- 限制深度：`{ deep: 1 }`（数字即可，不必 `true` 整棵树）。
- 清副作用：`onWatcherCleanup`（可从被 watch 调用的函数里注册；必须在同步阶段，不能放 `await` 之后）。`onCleanup` 参数仍可用。
- 暂停：`const { pause, resume, stop } = watch(...)`。不要为此再引 VueUse `watchPausable`。

## 其他 3.5 API

- **`useId()`**：表单 / 无障碍 id，SSR/CSR 稳定。禁止 `Math.random()`。
- SSR 下客户端必然不同的节点：`data-allow-mismatch`（可限 `text` | `children` | `class` | `style` | `attribute`）。
- 目标晚于 Teleport 挂载才出现：`<Teleport defer target="#box">`。
- SSR 异步组件懒水合（按需 import，利于 tree-shake）：

```ts
import { defineAsyncComponent, hydrateOnVisible, hydrateOnIdle, hydrateOnInteraction, hydrateOnMediaQuery } from 'vue'

defineAsyncComponent({ loader: () => import('./Comments.vue'), hydrate: hydrateOnVisible() })
defineAsyncComponent({ loader: () => import('./Footer.vue'), hydrate: hydrateOnIdle() })
defineAsyncComponent({ loader: () => import('./Widget.vue'), hydrate: hydrateOnInteraction('click') })
defineAsyncComponent({ loader: () => import('./Mobile.vue'), hydrate: hydrateOnMediaQuery('(max-width: 768px)') })
```

折页 `hydrateOnVisible`；非关键 `hydrateOnIdle`；交互才要活 `hydrateOnInteraction`（触发事件会重放）。纯 CSR 不必加 `hydrate`。

- 自定义元素才需要：`useHost` / `useShadowRoot`、`defineCustomElement` 的 `shadowRoot: false` / `configureApp`。
