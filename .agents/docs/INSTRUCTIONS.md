# 自定义指令

## 内部库

- 写代码前先用 docs-search 技能检索内部库用法，禁止凭训练数据猜测；文档与本仓库现状冲突时以仓库为准
- `@cat-kit/*`（slug：`cat-kit`）：TypeScript 工具库——core 通用工具、http 客户端、fe/be 前后端工具、crypto 安全随机、cli、tsconfig 预设
- `@veltra/*`（slug：`veltra-ui`）：Vue 3 组件与能力库——desktop/mobile 组件、ai 对话、sheet 电子表格、icons/compositions/utils/directives/styles、vite 按需解析
