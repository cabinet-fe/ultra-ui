# 自定义指令

## 涉及第三方库时，先用 docs-search 查库文档再写代码

1. **识别库与版本**：编码任务动手前，从任务描述、import 语句、`package.json` / `go.mod` 识别涉及的第三方库及本仓库锁定的版本。
2. **先查后写**：凡是调用库的 API、配置组件、传参、升级依赖、排查库相关报错，必须先用 `docs-search` 技能检索该库的官方文档（`search` 命中后用 `get` / `toc` 读具体章节），按文档写法落码；禁止凭记忆臆造 API 与参数。
3. **冲突以仓库为准**：文档写法与仓库现状冲突时，以仓库现状为准，并向用户点明差异。
4. **查不到如实说**：目标库未被 docs-search 收录或检索无结果时，如实说明并按仓库既有惯例处理，不得编造文档结论。

工具用法见 `.agents/skills/docs-search/SKILL.md`；服务地址读仓库根目录 `.pe.jsonc`。
